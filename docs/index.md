# pertTF

**pertTF is a transformer model designed for single-cell perturbation predictions.**

This site collects pertTF's installation instructions and tutorials in one
place. Tutorial pages here are the same files used elsewhere in the repo
(`demos/tutorials/`) — edit them there and this site picks up the change.
